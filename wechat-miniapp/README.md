# TEN BUT 微信小程序

这是网页游戏的原生微信小程序版本，适用于个人主体账号。它使用微信云开发，不依赖 `web-view` 或额外的服务器域名。

## 已实现

- 2–12 人房间、6 位房间码、5/10/20 轮
- A 盲抽 0–10 分；B 私下看到分数和四个情境；A 猜分后翻牌
- 自定义情境、实时文字同步、房主跳过、离开与自动转移房主
- 中文、English、日本語、한국어界面
- 中文和英文按住说话转文字
- 云函数只向描述者返回秘密分数和候选情境

## 首次导入

1. 登录微信公众平台，在“设置 → 第三方服务 → 插件管理”添加“微信同声传译”，插件 AppID 为 `wx069ba97219f66d99`。
2. 打开微信开发者工具，导入本目录 `wechat-miniapp`。
3. 将 `project.config.json` 中的 `touristappid` 换成你的小程序 AppID。AppID 可以提交到仓库；不要把 AppSecret 放进项目。
4. 在开发者工具中开通云开发环境。
5. 在云数据库中新建集合 `rooms`，权限选择“所有用户不可读写”（只允许云函数访问）。
6. 右键 `cloudfunctions/game`，选择“上传并部署：云端安装依赖”。
7. 编译，然后用两个不同微信号扫码测试多人房间。

## 体验版

开发者工具右上角选择“上传”，版本号建议 `0.1.0`，备注可写“首个朋友内测版”。上传后在小程序后台的版本管理中将该开发版设为体验版，并添加朋友为体验成员。

## 测试

在仓库根目录运行：

```bash
node wechat-miniapp/tests/game.test.cjs
```

## 语音说明

微信同声传译插件当前语音识别支持普通话和英语等有限语言。日语、韩语界面仍可完整游玩，但描述需要手动输入。
